Быстрый старт

Краткая документация по запуску

Пять шагов — от клонирования репозитория до первого забега. Команды указаны для Windows PowerShell; для Linux и macOS замените активацию окружения и copy на cp.

Python 3.11+ Node.js 20+ Docker или PostgreSQL 16
02
1

Клонируйте репозиторий

git clone https://github.com/byteguru8211/HotKey.git
cd HotKey
2

Запустите PostgreSQL

docker compose up -d db

Без Docker подойдёт локальный PostgreSQL 16 — укажите его строку подключения в .env.

3

Соберите фронтенд

cd frontend
npm install
npm run build
4

Установите бэкенд

cd ../backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
В .env укажите строку подключения из Docker:
DATABASE_URL=postgresql://hero:hero_password@127.0.0.1:5432/hero_typing
5

Запустите приложение

python run.py

Откройте http://127.0.0.1:5000 — Flask отдаёт API и собранный React-интерфейс на одном порту. Таблицы создаются автоматически.

Важно

  • Docker-база: пользователь hero, пароль hero_password, БД hero_typing.
  • Без PostgreSQL: приложение автоматически перейдёт на SQLite при ALLOW_SQLITE_FALLBACK=1.
  • Демо-рейтинг: игроки создаются автоматически; отключается через SEED_DEMO_DATA=0.
  • Полная документация: README.md и описание API — в репозитории.

Что проверить после запуска

01 Регистрация

Создайте аккаунт — профиль появится в рейтинге и сохранит прогресс.

02 Первый забег

15 секунд в режиме «Слова»: скорость, точность и комбо считаются на сервере.

03 Прогресс

Откройте статистику, достижения и рейтинг — данные придут из PostgreSQL.
